53. Security Requirements

The platform must implement:

Authentication
JWT Access Token
Refresh Token Rotation
Email OTP
Google OAuth
GitHub OAuth
Password Security
Argon2 (preferred) or bcrypt
Strong password policy
Password reset via OTP
API Security
Rate limiting
Helmet
CORS
Input validation
Zod validation
SQL injection protection
XSS protection
File Upload Security

Only allow:

PDF
DOCX

Maximum size:

10 MB

Virus scanning should be considered for future versions.

Role-Based Access

Roles:

Guest

↓

User

↓

Administrator

Administrator access must never be assignable from the frontend.
